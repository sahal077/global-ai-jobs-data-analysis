# Global AI Jobs 2026 — Data Analysis

A Python-based data analytics project exploring global AI job trends using data cleaning, exploratory analysis, and visualization.

### Key Areas

* AI job demand and specializations
* Salary and experience analysis
* Industry and geographic distribution
* Remote work and job types
* Job openings and applicant competition
* Job satisfaction and work-life balance

### Tools

Python, Pandas, NumPy, Seaborn, Matplotlib, Google Colab

This project demonstrates practical skills in data cleaning, EDA, visualization, and data-driven insights.
